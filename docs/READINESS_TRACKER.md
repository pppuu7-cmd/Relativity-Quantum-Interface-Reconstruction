# RQIR Readiness Tracker

**Purpose:** keep the user-requested readiness status explicit at every new research iteration from Iteration 116 onward.

Percentages are project-management estimates, not statistical confidence measures. They should move only when a gate materially changes the evidence base.

## Definitions

- **Paper III scientific-content readiness:** how much of the intended scientific argument/resource closure exists in reproducible repository form.
- **Paper III submission readiness:** scientific closure plus manuscript synthesis, figures/tables, literature/novelty audit, notation cleanup and final reproducibility packaging.
- **Candidate-Gravity start readiness:** how ready the RQIR repository is to accept and test a concrete dynamical gravity–quantum candidate through QG-001…QG-010.
- **Concrete Candidate-Gravity model itself:** progress on an actual dynamical model. This remains low until one model supplies its state space, dynamics, constraints, limits and derived RQIR observables.
