# RQIR Toy Model 006 — Complete Density-History Tomography No-Go

**Date:** 2026-08-29  
**Labels:** `DRV`, `NEG`, `OPEN`  
**Purpose:** determine whether Toy 005 can be upgraded all the way from a single matched Newtonian potential to an exact matched local-density history while retaining a different ordered/retarded response.

## 1. Main result

For a broad finite-dimensional one-particle class, demanding equality of the complete local occupation history

\[
\langle n_a(t)\rangle_+=\langle n_a(t)\rangle_-
\qquad\forall a,\forall t
\]

is already informationally complete: it determines the density matrix uniquely.

Under explicit sufficient conditions stated below,

\[
\boxed{
\langle n_a(t)\rangle_+=\langle n_a(t)\rangle_-\;\forall a,t
\Longrightarrow
\rho_+=\rho_-.
}
\]

Therefore all state-dependent kernels are equal,

\[
N_+=N_-,\qquad D_+=D_-,\qquad \chi^R_+=\chi^R_-.
\]

This yields a new conditional no-go:

> **RQIR-NG-003 — Generic complete density-history tomography obstruction.**  
> In a spectrally nonresonant finite-mode source whose evolving local-density projectors span the full Hermitian operator space, there is no nontrivial pair of distinct states with identical complete local-density history but different gravitationally relevant ordered response.

The conclusion is not universal; it identifies exactly which assumptions must fail for a stronger null pair to exist.

## 2. Setup

Consider a `d`-dimensional one-particle Hilbert space.

Let the Hamiltonian eigenbasis be

\[
H|i\rangle=E_i|i\rangle,
\qquad i=1,\ldots,d.
\]

Let localized/site states be

\[
|a\rangle=\sum_i V_{ia}|i\rangle,
\]

where `V` is unitary. The local one-particle occupation projectors are

\[
P_a=|a\rangle\langle a|.
\]

Their Heisenberg evolution is

\[
P_a(t)=e^{iHt}P_ae^{-iHt}.
\]

For two source states define

\[
\Delta=\rho_+-\rho_-.
\]

Equality of the complete local-density history is equivalent to

\[
\operatorname{Tr}[\Delta P_a(t)]=0
\qquad\forall a,t.
\]

Thus the question is purely one of the real operator span generated by the time-evolved projectors.

## 3. Sufficient conditions for informational completeness

Assume:

### A1 — nondegenerate positive Bohr gaps

For unordered pairs `i<j`, all positive gaps

\[
\omega_{ij}=E_j-E_i>0
\]

are distinct.

This is stronger than necessary but makes the proof transparent.

### A2 — every energy pair is visible in at least one site

For every `i<j`, there exists at least one site `a` such that

\[
V_{ia}V_{ja}^*\neq0.
\]

A sufficient generic special case is that all entries of `V` are nonzero.

### A3 — diagonal population matrix has full rank

Define the doubly stochastic/unistochastic matrix

\[
W_{ai}=|V_{ia}|^2.
\]

Require

\[
\boxed{\operatorname{rank}W=d.}
\]

## 4. Proof of RQIR-NG-003

Expand

\[
P_a(t)
=
\sum_i |V_{ia}|^2 |i\rangle\langle i|
+
\sum_{i<j}
\left[
V_{ia}V_{ja}^*e^{i(E_i-E_j)t}|i\rangle\langle j|
+\mathrm{h.c.}
\right].
\]

### Step 1 — diagonal sector

The zero-frequency components are

\[
P_a^{(0)}=\sum_i W_{ai}|i\rangle\langle i|.
\]

Because `rank(W)=d`, the real span of the `P_a^(0)` contains all diagonal Hermitian basis operators

\[
|i\rangle\langle i|.
\]

Thus the complete `d`-dimensional diagonal sector is observable.

### Step 2 — off-diagonal sectors

For each pair `i<j`, assumption A1 makes `omega_ij` a unique Fourier frequency. Therefore the cosine and sine Fourier components of `P_a(t)` at that frequency isolate the two Hermitian quadratures associated with that pair.

If

\[
c_{a,ij}=V_{ia}V_{ja}^*\neq0,
\]

then the two Fourier quadratures span

\[
X_{ij}=|i\rangle\langle j|+|j\rangle\langle i|,
\]

and

\[
Y_{ij}=-i|i\rangle\langle j|+i|j\rangle\langle i|,
\]

up to a nonsingular real rotation/rescaling determined by the phase of `c_{a,ij}`.

By A2, this works for every pair `i<j`.

There are

\[
2\binom d2=d(d-1)
\]

independent off-diagonal Hermitian directions.

### Step 3 — full operator space

Together with the `d` diagonal directions,

\[
\dim\operatorname{span}_{\mathbb R}\{P_a(t):a,t\}
=d+d(d-1)=d^2.
\]

But `Herm(d)` itself has real dimension `d^2`. Hence

\[
\boxed{
\operatorname{span}_{\mathbb R}\{P_a(t):a,t\}
=\operatorname{Herm}(d).
}
\]

If

\[
\operatorname{Tr}[\Delta P_a(t)]=0
\qquad\forall a,t,
\]

then `Delta` is Hilbert–Schmidt orthogonal to every Hermitian operator, and therefore

\[
\boxed{\Delta=0.}
\]

Thus

\[
\boxed{\rho_+=\rho_-.}
\]

Any state-dependent correlator, commutator or response constructed with the same dynamics is consequently identical.

QED.

## 6. Why this changes the Toy 006 target

The phrase “match the complete density history for all positions and all times” is too strong in a generic closed finite-mode model: it often performs full quantum-state tomography.

If it fully reconstructs `rho`, then asking simultaneously for

\[
\rho_+\neq\rho_-
\]

and a different response is logically impossible.

Therefore RQIR should not define a useful experimental null pair by requiring mathematically complete infinite-resolution source tomography.

The physically meaningful inverse problem is finite-resolution and operational:

\[
\boxed{
\text{Which source directions remain unobserved by the calibrated mean/noise channels,}
\text{ and does gravity respond to them?}
}
\]

## 7. Observability-rank formulation

For a finite experimental calibration set of observables/settings

\[
\mathcal M=\{M_\alpha\},
\]

define the real observation space

\[
\mathcal S_{\mathcal M}
=\operatorname{span}_{\mathbb R}\{M_\alpha\}.
\]

Its rank is

\[
\boxed{r_{\rm obs}=\dim\mathcal S_{\mathcal M}.}
\]

The mean-level invisible Hermitian subspace is

\[
\mathcal N_{\rm obs}
=\mathcal S_{\mathcal M}^{\perp},
\]

with dimension

\[
\boxed{\dim\mathcal N_{\rm obs}=d^2-r_{\rm obs}.}
\]

A nontrivial state-difference direction can exist only if

\[
r_{\rm obs}<d^2.
\]

For the ordered-kernel null problem, enlarge `S_M` by the symmetrized-kernel equality operators. A response witness exists exactly when at least one commutator/retarded operator has a nonzero projection into the remaining equality-nullspace.

This is the general linear-algebra structure already used implicitly in Toys 004–005, now promoted to an explicit reconstruction principle.

## 8. RQIR operational-null principle

A useful null test should match **all source information that the declared baseline experiment actually calibrates**, not an idealized mathematically complete data set that would already reconstruct the whole quantum state.

Therefore every future null-pair claim must record:

1. the calibrated observable set `M`;
2. the observation rank `r_obs` or its continuous-field analogue;
3. the remaining nullspace;
4. the target response operator's projection onto that nullspace;
5. detector precision and nuisance directions.

This prevents both under-calibration and impossible over-calibration.

## 9. How the no-go can be evaded

A distinct complete-density-history pair can survive only when the time-evolved density measurements are not informationally complete. Possible mechanisms include:

- degenerate/resonant Bohr gaps;
- symmetry-protected dark sectors;
- zero overlap structure between local and energy modes;
- rank-deficient `W=|V|^2`;
- restricted spatial access;
- finite time/bandwidth/sample sets;
- coarse-grained or smeared gravitational kernels rather than full local density;
- open-system dynamics with inaccessible environment variables;
- relativistic field sectors not reducible to a finite one-particle density tomography problem.

These are now **targets to classify**, not loopholes to ignore.

## 10. Relation to quantum tomography literature

Time-domain generation of informationally complete measurements is an established quantum-tomography idea: an initially incomplete measurement family can become informationally complete through known dynamics and repeated-time measurements.

Seed reference: A. Czerwinski, *Quantum state tomography with informationally complete POVMs generated in the time domain*, arXiv:2010.13777.

RQIR uses the same structural fact in reverse: if a proposed “matched source history” is informationally complete, then no hidden state direction remains for a response-only gravitational discriminator.
