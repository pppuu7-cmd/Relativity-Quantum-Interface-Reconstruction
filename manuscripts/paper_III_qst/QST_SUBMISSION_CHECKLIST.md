# QST submission checklist — Paper III

## Complete in this package

- Article type set to **Paper**.
- QST-facing title removes the internal series label from the title and foregrounds searchable quantum-sensing terms.
- Abstract is **255 words**, below IOP's usual 300-word maximum.
- Eight submission keywords are prepared.
- Manuscript is English, 12 pt, single column, with figures and tables embedded in the text.
- Introduction is reframed for the broader quantum-sensing / quantum-metrology audience.
- Top-level structure follows Introduction → Methods → Results → Discussion → Conclusion.
- References use a consistent numerical system and include DOI information where available.
- Data availability statement is included.
- Generative-AI use is disclosed in the Acknowledgments, as required by IOP policy.
- Scientific claims remain within the frozen Paper-III certificate: no experimental RQIR detection and no microscopic gravity-model selection.
- PDF compiles cleanly with no undefined citations/references and no overfull boxes.
- Cover letter is prepared.

## Author confirmation required before pressing Submit

1. **Competing interests:** confirm whether there are any financial or non-financial conflicts. If none, add the final journal declaration requested by ScholarOne/IOP.
2. **Funding:** confirm all funding sources and grant numbers, or confirm that there was no specific external funding.
3. **Originality/exclusivity:** confirm the manuscript is not under consideration by another peer-reviewed journal and complies with IOP's preprint policy.
4. **Data snapshot:** the GitHub repository is sufficient for the current data-availability statement; depositing a versioned archive in Zenodo or another DOI-issuing repository before publication would improve persistence and software/data citation.
5. **Peer-review choice:** this package uses single-anonymous review. QST also permits double-anonymous review if the author prefers it.
