# Candidate Gravity Assumptions Ledger Template

Every non-derived choice that can affect a physics claim must appear here.

| ID | Assumption | Scope | Type | Status | Sensitivity / failure consequence | Authority |
|---|---|---|---|---|---|---|
| A-001 | ... | dynamics / gauge / state / detector / approximation | structural / numerical / phenomenological | ACTIVE / TESTED / REJECTED / SUPERSEDED | ... | ... |

## Mandatory categories

- state-preparation assumptions;
- gauge fixing / relational construction;
- boundary/asymptotic conditions;
- perturbative/EFT truncation;
- regularization/renormalization;
- Markovian/Gaussian/stationary approximations;
- detector transfer/noise assumptions;
- source smearing and operator ordering;
- comparator exclusions;
- numerical tolerances and convergence assumptions.

## Discipline

1. No assumption may silently become a derived fact.
2. If a result changes materially when an assumption is relaxed, record the sensitivity and downgrade the claim.
3. Superseded assumptions remain in history with the new authority linked.
4. Assumptions inherited from Papers I–III must be named explicitly if the Candidate Gravity derivation depends on them.
