# Assumptions Ledger — ANSATZ-PQG-EFT-001 v0.1

## A-001 Background expansion
Assume an asymptotically Minkowski weak-field branch `g=eta+kappa h` with `|kappa h| << 1`.

## A-002 Matter sector
Use one real minimally coupled scalar field as the explicit matter model. This is a reference choice, not a claim that scalar matter is experimentally preferred.

## A-003 EFT domain
All predictions are restricted to energies/momenta well below the Planck scale and to a declared finite order in the EFT expansion.

## A-004 Gauge handling
Covariant gauge fixing and BRST ghosts are computational devices. Only BRST/relational/gauge-invariant combinations may enter physical RQIR claims.

## A-005 Renormalization
Stress-tensor composite operators and higher-curvature counterterms require an explicit renormalization prescription before numerical `J,N,chi^R` values are admissible. This remains unresolved in v0.1.

## A-006 Smearing
Local stress-tensor products are distributions; any detector/source observable must use declared spacetime smearing. The smearing kernel is not yet fixed.

## A-007 Initial state
No unique matter/graviton initial state is fixed in this iteration. The structural source hierarchy is state-parametric.

## A-008 Comparator identity
This ansatz is intentionally identified with comparator C5 at theory-class level. Therefore exact novelty against C5 is excluded by construction.

## A-009 No UV claim
The ansatz is not assumed to define a UV completion of gravity.

## A-010 No experimental claim
No detector SNR, Fisher advantage, runtime or new-physics signal follows from this reference instantiation alone.
